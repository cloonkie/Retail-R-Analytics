# Retail-R-Analytics

## Overview
Analysis of 2023–2025 RB eyewear sales to identify key drivers of sales performance across pricing, product attributes, seasonality, and account distribution.

## Key Questions
- Which price bands drive the most volume?
- What product attributes influence sales?
- How do accounts and phases differ?

## Methodology
- Data cleaning and feature engineering (season, price bins)
- Exploratory data analysis
- Linear regression modeling
- Bayesian high-performer classification

## Key Insights
- Higher MSRP tiers show diminishing unit velocity but stronger dollar contribution
- Product attributes (shape, material) significantly impact performance
- Sales patterns vary materially by account and seasonal timing
